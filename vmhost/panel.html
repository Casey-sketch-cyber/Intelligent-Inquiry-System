准备运行环境

正在检查安装和连接状态。

  1. 准备 Windows x64 安装镜像，并在运行窗口中完成系统安装。
  2. Windows 安装完成后，点击下方按钮挂载辅助组件，在虚拟机光驱中运行安装程序并重启。
  3. 在虚拟机中打开 \\VBOXSVR\TianxinSetup，以管理员身份运行 InstallGuest.cmd。
  4. 在虚拟机中安装 QQ 并由你本人登录。连接成功后，本页自动显示询价工作台。

默认只读验收，不发送消息。完成登录后分离窗口，保留虚拟机运行，再点「启动运行环境」恢复自动操作。虚拟机内的 Windows 必须保持登录。请勿在办公电脑上运行来宾初始化程序。
